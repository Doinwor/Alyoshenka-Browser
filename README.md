# Алешенька — русский национальный браузер

**Алешенька** — национальный браузер на Java и JavaFX. Открывая его, вы попадаете
в привычный, понятный и родной интернет — без чуждых шумов и навязчивых
иностранных платформ.

- **Наши сервисы**: поиск Яндекса, Госуслуги, МАКС, ВКонтакте, ВК Видео.
- **Наша защита**: каждый сайт проверяется; не русские сайты браузер не пропускает
  и подсказывает российский аналог.
- **Триколор**: сине-бело-красные акценты от загрузки до последней вкладки.
- **Открытая основа**: сделано своими руками на Java 21 и JavaFX.

## Скачать

Готовый дистрибутив для Windows x64: **[Алешенька.zip](site/Алешенька.zip)**.

Распакуйте архив и запустите `Алешенька.exe`. Ничего устанавливать не нужно —
внутри уже есть своя среда Java.

## Сборка из исходников

Требуется JDK 21. В корне проекта:

```bat
build.bat   :: компиляция
run.bat     :: запуск
```

Приложение читает картинки из папки `assets/`, поэтому запускайте из корня проекта.

## Структура

| Путь | Назначение |
|------|------------|
| `src/` | исходный код Java (JavaFX) |
| `assets/` | картинки и иконки браузера |
| `site/` | сайт-лендинг проекта (публикуется на GitHub Pages) |
| `lib/` | JavaFX SDK (не входит в репозиторий) |

## Сайт

Лендинг проекта публикуется автоматически на **GitHub Pages** из папки `site/`.
Открывайте локально `site/index.html` или смотрите живую версию по ссылке в описании
репозитория.
